# Brauhaus POS for iMin

Opens https://brauhauspos.lockandkeyhome.com inside an Android app and connects
the iMin built-in printer to it as `window.IminPrintInstance`, so the POS's
"Print receipt" button prints straight to the thermal roll.

Every upload to GitHub builds a new APK automatically (Actions tab, about 5 min).
The finished file is under **Releases** as `BrauhausPOS-iMin.apk`.
